# IBRATV

<p align="center"><img src="logo.png" width="180" alt="IBRATV"></p>

**مشغّل تلفزيون مباشر بواجهة زجاجية حمراء شفافة — للويندوز والأندرويد (موبايل، سيارة، تلفزيون) والآيفون.**
برمجة و تطوير **ابراهيم الخزرجي** — تليكرام: [t.me/ibraprogram](https://t.me/ibraprogram)

## المميزات

- خمس أشكال للواجهة: **زجاجي أحمر وأسود، زجاجي أبيض وأحمر، زجاجي أبيض، زجاجي شفاف، وحسب ستايل الجهاز** (يتبع الفاتح/الداكن ولون الويندوز) — Acrylic حقيقي على ويندوز 11، ودرجة شفافية قابلة للتعديل.
- **السينما**: مواقع الأفلام والمسلسلات تنفتح داخل التطبيق باسم ولوجو كل موقع، مع مانع إعلانات ونوافذ منبثقة مدمج (Ghostery على الويندوز، قائمة حظر مدمجة على الأندرويد والآيفون)، وإضافة/حذف المواقع.
- **مفضلة وحدة** تضيف وتمسح منها، وترتّبها أو تجمّعها حسب البلد أو النوع أو الدقة أو الحرف.
- إضافة قناة بنفسك برابط m3u8 أو رابط قناة يوتيوب مباشر (مثل الرابعة).
- ترتيب القنوات حسب **الدولة** (العراق أولاً ثم الدول العربية ثم العالم بالأعلام) أو **النوع** (أخبار، أفلام، مسلسلات، رياضة، أطفال…) أو **الاسم**.
- عرض **دقة** كل قناة عند توفرها (4K / FHD / HD / SD) مع فلتر للدقة، واختيار جودة البث أثناء التشغيل.
- **لوجو القناة** صغير بجانب اسمها.
- قوائم جاهزة من IPTV-org: العراق، القنوات العربية، الوطن العربي، الخليج، الشرق الأوسط، كل الدول العربية والجوار، كل قنوات العالم، الإنكليزية، وقوائم حسب النوع — مع إمكانية تثبيت أي قائمة في الشريط العلوي.
- إضافة رابط M3U خاص أو فتح ملف M3U من الحاسبة.
- المفضلة وسجل المشاهدة، بحث فوري، وتشغيل آخر قناة عند الفتح.
- **إشعار بوجود قنوات جديدة** وتطبيقها بضغطة، و**تحديث داخلي للبرنامج** (تنزيل وتثبيت من داخل التطبيق عبر إصدارات GitHub).
- يشغّل HLS ‏(m3u8) و MPEG-TS/FLV و DASH، ويحترم User-Agent / Referer الخاص بكل قناة.
- يحفظ نسخة من القوائم ليعمل حتى عند انقطاع الإنترنت المؤقت.

## النسخ

| الملف | الجهاز |
|---|---|
| `IBRATV-<ver>-Setup.exe` / `-portable.exe` | نسخة الويندوز |
| `IBRATV-<ver>-Android-Mobile.apk` | نسخة الموبايل |
| `IBRATV-<ver>-Android-Car.apk` | نسخة شاشات السيارة الأندرويد (كل القياسات) |
| `IBRATV-<ver>-Android-TV.apk` | نسخة التلفزيون والتيفي بوكس الأندرويد |
| `IBRATV-<ver>-iPhone.ipa` | نسخة الآيفون والآيباد (غير موقّعة — توقّعها بحسابك) |

نسخ الأندرويد الثلاث تنصّب سوية على نفس الجهاز، وكل وحدة مكتوب عليها اسم جهازها.

### توقيع الأندرويد التلقائي
أضف سرّين في **Settings → Secrets and variables → Actions** بالمستودع:
`IBRATV_KEYSTORE_B64` (ملف المفتاح بصيغة base64) و `IBRATV_KEYSTORE_PASSWORD`.
بعدها كل إصدار جديد يطلع موقّع وجاهز، وتحديثات التطبيق تنصّب فوق النسخة القديمة.

## الرجوع للنسخة بدون السينما
الفرع `before-cinema` بالمستودع فيه آخر نسخة قبل إضافة السينما (v2.4.1).

| Enter | تشغيل القناة |
| PageUp / PageDown | القناة السابقة / التالية |
| Space | تشغيل / إيقاف |

| M | كتم الصوت |
| S | إضافة للمفضلة |

## البناء

```bash
npm install
npm start      # تشغيل للتجربة
npm run dist   # بناء المثبّت والنسخة المحمولة لويندوز
```

كل دفع (push) إلى `main` يبني البرنامج تلقائياً عبر GitHub Actions وينشر إصداراً باسم `v<version>`.
**لإصدار تحديث جديد:** ارفع رقم `version` في `package.json` واكتب ملاحظات التحديث في `CHANGELOG-latest.md` — البرامج المثبّتة ستُظهر إشعار التحديث وتثبّته داخلياً.
